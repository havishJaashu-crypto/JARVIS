## ULTRON Orb UI gesture interaction

This JARVIS project adapts the orb interaction pattern (drag/pinch rotation and two-hand pinch zoom) from [ultron-by-sagar-builds](https://github.com/SAGAR-TAMANG/ultron-by-sagar-builds), by Sagar Tamang. The source repository identifies this work as MIT licensed. Its orb renderer has been reimplemented for this lightweight static JARVIS page; the project does not copy the ULTRON branding or its original Three.js scene source.
